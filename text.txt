Here's the complete guide for running **ContentOS** locally on Windows:

---

## 📦 1. Install Dependencies (one-time)

```powershell
cd d:\smm-panel-5
npm install
```

---

## 🗄️ 2. Start Database (PostgreSQL) + Redis

This single command downloads & starts an **embedded PostgreSQL** and **Redis** for you automatically:

```powershell
npm run local:services
```

> Keep this terminal **open** — it runs Postgres on `127.0.0.1:5432` and Redis on `127.0.0.1:6379`. Killing it stops both services.

---

## 🔄 3. Run Database Migrations

```powershell
npm run build:api
npm run migrate
```

This compiles the backend TypeScript and applies all SQL migration files ([001_auth.sql](cci:7://file:///d:/smm-panel-5/001_auth.sql:0:0-0:0) → [007_ai_knowledge.sql](cci:7://file:///d:/smm-panel-5/007_ai_knowledge.sql:0:0-0:0)).

---

## 🖥️ 4. Start Backend API (NestJS)

```powershell
npm run start:api
```

- API runs on **`http://localhost:3001`**
- All endpoints are under `/api/v1/...`

---

## 📖 5. Swagger UI

Once the backend is running, open in browser:

```
http://localhost:3001/api/docs
```

> Swagger is **only available** when `APP_ENV` ≠ `production` (set in [.env](cci:7://file:///d:/smm-panel-5/.env:0:0-0:0)).

---

## 🌐 6. Start Frontend (Vite + React)

In a **new terminal**:

```powershell
npm run dev
```

- Frontend runs on **`http://localhost:5173`**
- API calls are auto-proxied from `/api` → `http://127.0.0.1:3001`

---

## 📧 7. Start Mail Worker (optional)

```powershell
npm run start:mail
```

Processes email queue (verification codes, notifications).

---

## ⚙️ 8. Start Background Worker (optional)

```powershell
npm run start:worker
```

Processes AI/PDF jobs via BullMQ.
